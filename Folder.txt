app/	Pages, layouts এবং API routes
components/	Reusable UI components
config/	Application configuration
lib/	Database/API-এর core utilities
models/	Mongoose schemas/models
services/	Business logic
constants/	Fixed routes/messages/constants
utils/	ছোট reusable helper functions
public/	Static images, icons ইত্যাদি




আমাদের API request-এর flow হবে:

Frontend
   ↓
app/api/
   ↓
Service
   ↓
Model
   ↓
MongoDB Atlas

উদাহরণ:

GET /api/destinations
        ↓
destinations/route.js
        ↓
destinationService.js
        ↓
Destination.js
        ↓
MongoDB Atlas

এতে route.js-এর মধ্যে database/business logic গুঁজে দিতে হবে না।
